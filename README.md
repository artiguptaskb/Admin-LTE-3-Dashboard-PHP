# PHP Admin Dashboard

## Project Overview
A web-based Admin Dashboard developed using PHP, MySQL and AdminLTE 3. It provides an interface to manage users and different administrative operations.

## Key Features
- User Management
- Team Structure Management
- Lead Management
- Attendance Management
- Client Visit Management
- Project Management
- Sales Management
- Reports Module
- Role-Based Access Management

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- AdminLTE 3

## Installation
1. Clone this repository.
2. Place the project folder inside the XAMPP `htdocs` directory.
3. Start Apache and MySQL.
4. Import the provided sample database into phpMyAdmin.
5. Configure your local database credentials.
6. Open `http://localhost/php-admin-dashboard/` in your browser.

## Project Purpose
This project demonstrates PHP-based web application development, database connectivity and administrative dashboard functionality.
